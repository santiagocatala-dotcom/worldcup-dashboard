🎯 ¿Cómo usar esto?
1. Buscá un partido en tu casa de apuestas
2. Ingresá las cuotas que ofrecen (decimales: ej. 1.20, 5.50)
3. Ingresá tu probabilidad estimada (0-100%) basada en datos, forma, historial
4. El dashboard te dice si hay Value (Valor Esperado Positivo) ✅ o no ❌

⚠️ Importante: La casa siempre tiene margen. Solo apostá cuando tu estimación de probabilidad sea mayor que la probabilidad implícita de la cuota.

💡 Explicación

Value Bet = cuando tu probabilidad estimada es MAYOR que la probabilidad implícita en la cuota de la casa.


Fórmula: Value = (Cuota × Tu Probabilidad) − 1

Si Value > 0 → ✅ Tiene Valor Esperado Positivo

Si Value < 0 → ❌ No tiene valor, la casa tiene el edge


Ejemplo: Argentina @1.20 → casa estima 83.3%. Si creés que gana 92% → Value = (1.20 × 0.92) − 1 = +10.4% ✅

📐 Criterio de Kelly — La fórmula matemática para maximizar el crecimiento de tu bankroll a largo plazo.
Kelly Stake (%) = ( (Cuota × Probabilidad) − 1 ) / (Cuota − 1)

⚠️ Recomendación: Usar Kelly Fraccionario (25-50%) para reducir volatilidad. Nunca más del 5% del bankroll en una apuesta.
